# Support

Need help with Ethos? Use the options below depending on the issue.

## Questions

For questions about the code, build process, or current development, open a GitHub Discussion if the repository has Discussions enabled. Otherwise, open an issue and clearly explain what you need help with.

Before asking, check the README and existing issues to see whether the question has already been answered.

## Bug Reports

If something does not work as expected, open a GitHub issue with the following information:

- What you were trying to do.
- What happened.
- What you expected to happen.
- Steps to reproduce the problem.
- Build output or error messages, if available.
- Your host operating system and QEMU version, if relevant.

For boot or kernel errors, include serial output or other relevant logs when possible.

## Build Problems

If Ethos fails to build or run:

1. Make sure you are using the latest version of the repository.
2. Check that the required build tools are installed.
3. Run the build or test command again and save the complete output.
4. Include the output when reporting the problem.

Please avoid posting only a screenshot when you can provide the actual error text.

## Feature Requests

Feature requests are welcome. Describe the feature, why it would be useful, and how you expect it to work.

Keep in mind that Ethos is still under development, so proposed features may not be implemented immediately.

## Security Issues

Do not publish details of a potential security vulnerability in a public issue before the problem has been assessed.

Use GitHub's private vulnerability reporting feature if it is enabled for the repository. Otherwise, contact the project maintainer privately.

## Before Opening an Issue

- Search existing issues for the same problem.
- Use a clear and specific title.
- Include enough information to reproduce the issue.
- Keep unrelated problems in separate issues.

Thank you for taking the time to report problems and help improve Ethos.
