# Features

These pages describe facilities you can use in the current kernel. They also call out limits that affect everyday testing.

- [Ethernet](ethernet.md) covers the E1000 frame driver and current protocol limits.
- [Display server](display-server.md) covers text-cell windows, focus, drawing, and input routing.
- [Ping](ping.md) explains hostname lookup and ICMP echo over QEMU networking.
- [Wi-Fi: Intel AX201](wifi.md) describes device detection, firmware staging, and driver work still missing.
- [APX executables](apx-executables.md) follows the command packaging and loading path.
- [Process management](process-management.md) explains PIDs, task state, and weighted scheduling.
- [RAMFS](ramfs.md) lists file limits and writable paths.
- [Shell](shell.md) covers built-ins and external commands.
- [Typer](typer.md) documents editing and save controls.
- [System call interface](syscalls.md) documents the user API and its current limits.
